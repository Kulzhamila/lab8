# Жатақхана бөлмелерін брондау жүйесі (Dormitory Booking System)

## Жоба туралы
Бұл веб-қосымша студенттерге жатақханадағы бос бөлмелерді іздеуге, оларды жатақхана, бөлме түрі және бағасы бойынша сүзуге және бөлмені онлайн брондауға мүмкіндік береді. Әкімші жатақханаларды, бөлмелерді және брондау өтінімдерін басқарады. Жоба PHP және MySQL көмегімен әзірленеді.

## Негізгі мүмкіндіктер
- Пайдаланушыларды тіркеу және кіру (Authentication)
- Студент және әкімші рөлдері
- Жатақханалар мен бөлмелерді қосу, қарау, өңдеу және жою (CRUD)
- Бөлмені брондау, өтінімді өзгерту және болдырмау
- Әкімшінің өтінімдерді растауы немесе қабылдамауы
- Бөлме нөмірі бойынша іздеу
- Жатақхана, бөлме түрі, баға және бос орын бойынша сүзу
- Бір бөлменің бір мерзімде қайталап брондалуын болдырмау
- Қауіпсіздік және деректерді валидациялау

## Дерекқор құрылымы (Tables)
- **users**: Пайдаланушы мәліметтері (студенттер мен әкімшілер)
- **dormitories**: Жатақханалар туралы ақпарат
- **rooms**: Бөлмелер (нөмірі, қабаты, сыйымдылығы, бағасы, күйі)
- **amenities**: Бөлмедегі ыңғайлылықтар (Wi-Fi, душ, үстел т.б.)
- **room_amenities**: Бөлмелер мен ыңғайлылықтардың байланысы
- **bookings**: Брондау өтінімдері мен олардың статусы

## Беттер
- Басты бет, тіркелу, кіру
- Бөлмелер каталогы және бөлме туралы бет
- Брондау формасы, менің брондауларым, профиль
- Әкімші панелі: жатақханалар, бөлмелер, брондаулар, пайдаланушылар

## Технологиялар
- Frontend: HTML5, CSS3, JavaScript, Bootstrap
- Backend: PHP
- Database: MySQL (PDO арқылы қосылу)
