# Беттер мен функциялар тізімі

## 1. Жалпыға ашық беттер (тіркелусіз)

| № | Бет | Файл | Функциялар |
|---|-----|------|-----------|
| 1 | Басты бет | `index.php` | Жүйе туралы қысқаша ақпарат, жатақханалар тізімі, бос бөлмелер саны |
| 2 | Тіркелу | `register.php` | Аты-жөні, email, телефон, жыныс, құпиясөз енгізу; деректерді тексеру; құпиясөзді хэштеу |
| 3 | Кіру | `login.php` | Email мен құпиясөз арқылы кіру, сессия ашу |
| 4 | Бөлмелер каталогы | `rooms.php` | Бөлмелер тізімі; **іздеу** (бөлме нөмірі бойынша); **сүзу** (жатақхана, бөлме түрі, баға аралығы, ыңғайлылықтар, бос/бос емес); беттерге бөлу (пагинация) |
| 5 | Бөлме туралы | `room.php?id=` | Бөлменің толық сипаттамасы, ыңғайлылықтар, бос күндер, «Брондау» батырмасы |

| users | Тіркелу | Профиль, әкімші | Профиль, рөл | Әкімші |
| dormitories | Әкімші | Барлығы | Әкімші | Әкімші |

## 5. Брондау статусының өмірлік циклі

```
pending ──(әкімші растайды)──► approved
   │
   ├──(әкімші бас тартады)───► rejected
   │
   └──(студент болдырмайды)──► cancelled
```

## 6. Деректерді тексеру ережелері

- **Email** — `filter_var($email, FILTER_VALIDATE_EMAIL)`, бірегейлігі тексеріледі
- **Құпиясөз** — кемінде 8 таңба, әріп пен сан болуы тиіс; екі рет енгізу сәйкес келуі керек
- **Телефон** — `+7XXXXXXXXXX` форматы (regex)
- **Күндер** — `start_date` бүгіннен кейін, `end_date > start_date`
- **Бос орын** — сол мерзімдегі `approved` брондаулар саны `capacity` мәнінен аспауы керек
- **Сандар** — баға ≥ 0, сыйымдылық 1–6
- Барлық тексеру **сервер жағында** (PHP) жүргізіледі; HTML5 атрибуттары (`required`, `type="email"`) тек қосымша
